## 0. Scope — read this first

This is a **brand asset kit**, not a UI specification.

**What Brand Studio supplies:** the logo system, the mascot and its Character Bible, the family's
character drawing language, brand colour and accent principles, the type family, the icon style,
the OSMANTH endorsement, favicons, OG and social assets, brand illustration, and the rules for
using those assets.

**What Brand Studio does not decide, and this document does not constrain:**

- Page layout and information architecture
- Component geometry: radii, shadows, borders, spacing, CSS of any kind
- Where the upload, the destination picker, the preflight result and the download go
- How the six statuses are organised, placed or worded — those words are the product's
- The 13 SEO entrances, the 25 print profiles, and the route structure
- The fix planner, the verification engine and every engineering decision behind them
- Mobile interaction behaviour, motion, copy and features

Those are the Image team's decisions. **The one thing this kit asks for is a colour change**, and
the reason is measured below rather than asserted.

## 1. The creature

Osmanth Image is the family character with one object: a set square, carried in the right
hand.

| | |
|---|---|
| Silhouette rule | Osmanth Image: a square body with floppy ears, carrying a set square - the only triangle in the family, which is what keeps it legible once the tick marks disappear at small sizes. The square body is measured rather than chosen for looks: the derived silhouette sat 0.0304 from Osmanth Video's. Inherits the family's eye language, outline weight and corner softness. |
| Signature traits | set square prop · cutting mat green · refuses to invent pixels |
| Primary shapes | 7 |
| Object | A set square, carried — not worn |
| Closest sibling mark | WATCH, at 0.0473 against a 0.03 bar |

**Why a set square.** Six siblings carry a rounded rectangle of some kind — a page, a printer, a
lantern, a clapperboard — and a seventh would have joined them; the remaining one carries a circle
on a stick. A triangle is the one outline this family does not have, so the silhouette survives on
its own once the tick marks disappear below about 24px. It is also the right object: this product's
job is size, squareness and trim.

**Never:**

- Never change the square body shape or the head-to-body ratio by more than 10%.
- Never recolour the body away from #15471b; seasonal palettes swap accents only.
- Never change eye style from "round" - expressions swap the eye state, not the eye design.
- Never remove or restyle the floppy ears.
- Never add fingers, detailed teeth, or realistic shading.
- Never render the character with a visible nose if the Bible says it has none.

### Expressions and poses in the kit

Expressions: neutral, happy, thinking, surprised, sleepy.
Poses: idle, wave, point, think, sit, cheer, jump.

Each is a part swap or a transform on the same geometry, so none is a new drawing and none can
drift.

## 2. Colour

### The accent, and why it has to move

This product's **entire output is a status**. Every run ends in one of six words:

| state | meaning |
|---|---|
| `READY` | Verified against the destination, with nothing left to say. |
| `READY_WITH_WARNINGS` | Printable, with something the person should know first. |
| `FIXABLE` | Not ready yet, and the fix is one this product can perform locally. |
| `REVIEW_RECOMMENDED` | A human should look. Too few pixels always lands here at best. |
| `NOT_RECOMMENDED` | Do not print this here. |
| `UNVERIFIED` | The profile's own source could not be confirmed. Said, not hidden. |

The colour it ships, `#2f5d50`, collides three ways — and the worst collision is not with
a sibling:

| measured | result |
|---|---|
| `#2f5d50` vs its own --ok `#2e7d4f` | **0.044** |
| `#2f5d50` vs Check Before Publish `#1f7a63` | **0.084** |
| `#2f5d50` vs its own --info `#3d5a80` | **0.085** |

The first row decides it. A brand colour that close to **READY** makes the one thing this product
must say unambiguously ambiguous. For scale, the family's own accents are never closer to each other
than 0.146.

only room left was at the dark end of the wheel, and an accent that measures like ink is not a
colour.

### Two findings, and the second outlives this product

**The lightness band the first eight happen to occupy is not a rule.** The system marks the accent
`VARIABLE` and asks only for measurable separation. Sweeping inside that band out of habit made it
look as though the family had run out of colour: the best in-band candidate measured **0.126**,
below the 0.146 the other eight keep between themselves.

**But stepping outside it does not buy what the numbers claim.** The distinctiveness measure is a
pixel difference, so **it rewards a change in lightness**. Four navy candidates scored 0.156–0.183
against Osmanth Watch's indigo; rendered side by side, every one read as *Watch, darker* rather than
as a second brand.

> The measure cannot answer the family board's question — *can you tell them apart?* — and on this
> product it was not allowed to. Any future child whose accent is chosen at a different lightness
> from its nearest sibling must be looked at, not only measured.

### Cutting Mat `#15471b`

**The meaning came last, not first.** A self-healing cutting mat is this colour, and it is the
surface trimming, bleed and sizing actually happen on.

## 5. Endorsement, and the sibling this hands off with

`An Osmanth product`, **parent-prefixed** — named outward from the parent on a
parent domain, like Watch, Docs and Video.

### Check Before Submit

| **Check Before Submit** | PDFs. Page size, bleed, fonts, colour, encryption, and the resolution of images inside a PDF. |
| **Osmanth Image** | Images - JPEG, PNG, WebP. Checks them, fixes what can be fixed, and produces the print file. |
| **A PDF uploaded here** | Answered with a link to Check Before Submit rather than a refusal. |
| **The three Adobe Stock tools** | Stay with Check Before Submit. They read JPEGs, but the job is submission review, not print preparation. |
| **Sequencing, from the handoff document** | Check Before Submit must not drop its image routes until this product is live and reachable. Otherwise users have nowhere to go and the rankings transfer nowhere. |

This boundary is **the product's own**, dated 2026-09-21 and written into its repository before this
brand existed. The brand records it; it did not make it and does not move it.

What the brand adds: these two must be **separable at a glance**, because they are the only pair a
user is handed between mid-task. Measured at 0.231.

## 6. Icons and illustration

The family's icon set, at the family's stroke weight. The 13 SEO entrances and 25 print profiles are
the product's own information architecture and the brand does not rename them.

**Illustration:** flat, the family's outline weight, no gradients. **No before/after sharpening, no
upscale comparison, nothing that implies detail appearing.** This product removed AI enlargement on
2026-09-21 and answers too-few-pixels with *print smaller*. A brand image that implies otherwise
sells against the engine.

## 9. Using the assets

- The mark's geometry is fixed. Recolour through tokens; never redraw.
- The set square is signature: the character does not appear without it in brand contexts.
- On a dark surface the mark's outline token measures near-identically to the dark card. Use the
  reversed lockup or recolour the outline — a family-wide gap recorded in decision 0019.
- The endorsement lockup is not optional on brand surfaces.
- Nothing here is a trademark clearance.

## 11. The family system behind this

### A · Brand Family DNA

| | area | rule |
|---|---|---|
| **LOCKED** | Character / One body language | A single rounded mass with a head, flat fill, no shading and no gradients. 5-9 primary shapes. Head-to-body 0.44-0.6. |
| **LOCKED** | Character / Eye language | Eye style stays within round / oval / dot. Expressions swap the eye state, never the eye design. |
| **LOCKED** | Character / Stroke & corner language | Outline width 0.01-0.015 of the body unit; corner softness 0.7-1. The same weight and softness govern the icon set and any brand illustration. |
| **VARIABLE** | Character / Each product's own creature | Every product has its own animal: its own body style, ears, tail and proportions inside the bands above. Measured against every sibling, not against nothing. |
| **VARIABLE** | Character / Each product's own object | One object the character carries, naming what the product does. No two family members carry the same object, checked as drawn rather than as named. |
| **LOCKED** | Character / The parent mark carries nothing | Osmanth itself has no prop, no badge and no facial detail beyond eyes and mouth. It is the plainest member on purpose. |
| **LOCKED** | Colour / The parent's gold | #d99a2b belongs to Osmanth. No child uses it as its accent. |
| **VARIABLE** | Colour / Each product's own accent | One accent per product, and it must be measurably separable from every sibling's as rendered swatches. Two products a returning visitor cannot tell apart by colour are one product with two names. |
| **LOCKED** | Colour / How an accent is spent | One accent, used sparingly. It never carries status or confidence - success, warning and failure are the product's own semantic colours, and the accent must be measurably clear of them. |
| **LOCKED** | Colour / Contrast floor for brand colour | Wherever a brand colour is used as text or as a text background it clears 4.5:1, and large or non-text uses clear 3:1 - in light and dark alike. |
| **INHERITED** | Colour / The shared secondary | #f1e7cb is the family's shared warm tint, used behind marks and in brand surfaces. |
| **LOCKED** | Typography / Type family | System UI. The system stack, so no product page ships a render-blocking webfont. Inter is the single exception and only for the wordmark, self-hosted and subset. |
| **VARIABLE** | Typography / A second voice for data | A product whose subject is numbers, times or machine output may take a monospace voice for that content. It is a family-approved option, not a requirement, and never decoration. |
| **LOCKED** | Graphic language / Icon style | One line set, drawn at the family stroke and corner softness. 32 icons. Never mixed with a third-party set. |
| **VARIABLE** | Graphic language / Business symbols | Each product picks the icons its own subject needs, and its own object. |
| **LOCKED** | Graphic language / Illustration | The character and the icon set are the whole illustrated vocabulary. No spot illustration, no scene art, no stock imagery, no gradient mesh, no photography of people. |
| **LOCKED** | Endorsement / The lockup | Exactly "An Osmanth product". Never paraphrased, never translated on an English page. |
| **VARIABLE** | Endorsement / Endorsement model | parent_prefixed / independent_endorsed / unlisted. Products named outward from the parent take the prefixed lockup; independent keyword brands are endorsed rather than renamed. |
| **INHERITED** | Endorsement / Where it appears | Footer on every page, and under the wordmark in the header on independent-brand sites. Never larger than the child's own wordmark. Never smaller than 12px. |
